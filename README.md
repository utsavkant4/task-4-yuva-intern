# India Air Quality Analysis (2015-2020)

Yuva Intern Task 4: Data Science Tool Mastery Project.

End-to-end analysis of India air quality data (2015-2020) using Python, PostgreSQL and Power BI.

## Dataset
Air Quality Data in India (Kaggle), file station_day.csv: 108,035 rows from 110 monitoring stations, daily readings from 01-01-2015 to 01-07-2020. After cleaning: 86,754 rows and 19 columns.

## Tools
Python (pandas, NumPy, Matplotlib, Seaborn), Jupyter Notebook, PostgreSQL (SQL), Power BI, Git and GitHub.

## Key findings
- PM2.5 (0.86) and PM10 (0.73) have the strongest correlation with AQI.
- Winter and Post-Monsoon are the most polluted seasons; Monsoon is the cleanest.
- Delhi stations make up 8 of the top 10 most polluted stations.
- About 33% of days fall in the Poor, Very Poor or Severe categories.
- Station coverage grew from 21 (2015) to 101 (2019), so year-wise trends need careful reading.
